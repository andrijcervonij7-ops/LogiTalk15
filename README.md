Logi talk — це легкий та зручний застосунок для обміну повідомленнями в режимі реального часу. Застосунок має сучасний темний інтерфейс (Dark Mode) та інтуїтивно зрозуміле керування.

📸 Інтерфейс
Головний екран та налаштування профілю

✨ Основні можливості

👤 Профіль користувача: Зручна зміна нікнейму безпосередньо у бічному меню.

💬 Обмін повідомленнями: Надсилання та отримання повідомлень у реальному часі.

🔍 Пошук: Швидкий пошук повідомлень або користувачів через спеціальну панель.

🔔 Системні сповіщення

🌙 Темна тема: Стильний темний дизайн, що зменшує навантаження на очі.
